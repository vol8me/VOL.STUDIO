# Oyunlar ve Geliştirici Araçları i18n Sistemi

## Genel

Her oyun ve geliştirici aracı kendi namespace'ine sahiptir. Oyun çevirileri
`games/{oyun}/src/i18n/{tr,en}.json`, araç çevirileri
`devtools/{araç}/src/i18n/{tr,en}.json` konumundadır. Yüzey başlatılırken
`bootstrap.ts` (vol-hell) veya `main.ts` (vol-ui) içinde `i18n.addResources()`
ile yüklenir.

## vol-hell

### Yapı

```
games/vol-hell/src/i18n/tr.json
games/vol-hell/src/i18n/en.json
games/vol-hell/src/app/bootstrap.ts   — i18n başlatma
```

### Namespace: `volhell:`

```typescript
import { i18next } from '@volstudio/core';
const label = i18next.t('volhell:menu.start');
```

### Başlatma (bootstrap.ts)

```typescript
import { i18n } from '@volstudio/core';
import volhellTr from '@/i18n/tr.json';
import volhellEn from '@/i18n/en.json';

i18n.addResources('tr', 'volhell', volhellTr);
i18n.addResources('en', 'volhell', volhellEn);

await i18n.init({ saveManager });
```

`addResources()` init öncesi çağrılır — pending kuyruğuna alınır, init sonrası uygulanır.

### Sahne Yapısı

Her sahne `languageChanged` olayına abone olmalı ve `SHUTDOWN`'da aboneliği kaldırmalı:

```typescript
private readonly onLanguageChanged = (): void => {
  this.titleText.setContent(i18next.t('volhell:menu.title'));
  this.startButton.setLabel(i18next.t('volhell:menu.start'));
};

create(): void {
  // UI oluştur, i18next.t() ile
  i18next.on('languageChanged', this.onLanguageChanged);
}

onShutdown(): void {
  i18next.off('languageChanged', this.onLanguageChanged);
  // Diğer temizlik
}
```

### Mevcut Key Grupları

Tam liste `games/vol-hell/src/i18n/tr.json` içindedir; burada yalnızca üst
seviye gruplar tutulur — tek tek key listesi kopyalandığı anda eskir.

```
volhell:menu.*      — ana menü
volhell:loading.*   — yükleme ekranı
volhell:hud.*       — HUD (can, dash, dalga, ekonomi)
volhell:settings.*  — ayarlar ekranı
volhell:pause.*     — duraklatma ekranı
volhell:death.*     — ölüm/koşu sonu ekranı
volhell:cards.*     — kart adları, açıklamaları ve dükkân metinleri
volhell:ability.*   — ability adları ve slot etiketleri
volhell:enemy.*     — düşman etiketleri
```

### Yeni String Ekleme

1. `games/vol-hell/src/i18n/tr.json`'a key ekle
2. `games/vol-hell/src/i18n/en.json`'a aynı key'i ekle
3. Kodda `i18next.t('volhell:yeni.key')` ile kullan
4. Sahne içinde `languageChanged` listener'ına güncelleme ekle

## vol-ui

### Yapı

```
devtools/vol-ui/src/i18n/tr.json
devtools/vol-ui/src/i18n/en.json
devtools/vol-ui/src/main.ts             — i18n başlatma
devtools/vol-ui/src/scenes/ShowcaseScene.ts — tab yönetimi + dil değişimi
```

### Namespace: `volui:`

```typescript
import { i18next } from '@volstudio/core';
const label = i18next.t('volui:buttons.primary');
```

### Başlatma (main.ts)

```typescript
import { i18n } from '@volstudio/core';
import trResources from './i18n/tr.json';
import enResources from './i18n/en.json';

i18n.addResources('tr', 'volui', trResources);
i18n.addResources('en', 'volui', enResources);

await i18n.init();
```

### Tab Yapısı

Her tab dosyası (`devtools/vol-ui/src/sections/*Tab.ts`) bir builder fonksiyonu dışa aktarır. `ShowcaseScene` dil değişiminde tüm tab'leri yok eder ve yeniden inşa eder — bu sayede tüm `i18next.t()` çağrıları yeni dile göre yeniden çalışır.

### Module-Level `i18next.t()` Tuzağı

Tab dosyalarında module-level constant'larda `i18next.t()` KULLANMA. Import sırasında `i18n.init()` henüz tamamlanmamıştır — boş string döner.

Yanlis:

```typescript
const UNIT_ROWS = [
  { name: i18next.t('volui:advanced.archerUnit') }, // bos string!
];
```

Dogru:

```typescript
function buildDataTableDemo(disposables: Destroyable[]): HTMLElement {
  const unitRows = [
    { name: i18next.t('volui:advanced.archerUnit') }, // init sonrasi, calisir
  ];
}
```

### Dinamik Key Pattern'i

Mapping tablosu + `i18next.t(degisken)` pattern'i geçerlidir. Static analyzer bu key'leri yakalayamaz — manuel doğrulanmalı.

```typescript
const VARIANT_KEYS: Record<BarVariant, string> = {
  health: 'volui:hud.health',
  stamina: 'volui:hud.stamina',
  cooldown: 'volui:hud.cooldown',
};

// Kullanim:
return card(i18next.t(VARIANT_KEYS[variant]), wrap);
```

Template literal ile dinamik key:

```typescript
const dirKey = `volui:touch.dir_${event.direction}`;
const directionLabel = i18next.t(dirKey);
```

Bu key'lerin JSON'da varlığı manuel doğrulanmalı: `touch.dir_up`, `touch.dir_down`, `touch.dir_left`, `touch.dir_right`.

### Yeni String Ekleme

1. `devtools/vol-ui/src/i18n/tr.json`'a key ekle
2. `devtools/vol-ui/src/i18n/en.json`'a aynı key'i ekle
3. Tab builder fonksiyonu içinde `i18next.t('volui:namespace.key')` ile kullan
4. `ShowcaseScene` dil değişiminde tab'leri yeniden inşa ettiği için ekstra listener gerekmez

## Ortak Kurallar

- **tr.json ve en.json key parity zorunludur.**
- **Hardcoded UI string yasaktır.**
- **Module-level `i18next.t()` yasaktır.**
- Sayısal değerler, CSS class adları, font adları çevrilmez.
- `i18next.t()` interpolasyon parametreleri: `i18next.t('volhell:wavecounter.wave', { wave: 5 })` → `"Dalga 5"`
