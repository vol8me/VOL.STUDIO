# Yüzey i18n'i

CORE'un i18n altyapısı [core/docs/i18n.md](../../core/docs/i18n.md)'dedir. Bu
belge onu TÜKETEN yüzeylerin (oyunlar ve geliştirici araçları) uyması gereken
kuralları anlatır.

## Desen

Her yüzey kendi namespace'ine sahiptir ve çevirilerini `src/i18n/{tr,en}.json`
altında tutar. Yüzey açılırken kaynakları kaydeder, sonra init eder:

```ts
import { i18n } from '@volstudio/core';
import tr from '@/i18n/tr.json';
import en from '@/i18n/en.json';

i18n.addResources('tr', 'volhell', tr);
i18n.addResources('en', 'volhell', en);
await i18n.init({ saveManager });
```

`addResources()` init'ten ÖNCE çağrılabilir — kaynak kuyruğa alınır ve init
sonrası uygulanır.

Namespace listesi burada tekrarlanmaz; tek kaynak JSON dosyalarının kendisidir.

## Üç kural

**Metin hard-code edilmez.** Kullanıcıya görünen her dize bir anahtardan gelir.
Sayısal değerler, CSS sınıf adları ve font adları metin değildir.

**`tr.json` ve `en.json` anahtar paritesi zorunludur.** Her yüzette bunu
doğrulayan bir `keyParity` testi bulunur.

**Module seviyesinde `i18next.t()` yasaktır.** Import anında `i18n.init()`
bitmemiştir; çağrı sessizce boş string döner. Çağrı, yüzeyi kuran fonksiyonun
İÇİNDE olmalıdır:

```ts
// YANLIŞ — import anında çalışır, boş string
const ROWS = [{ name: i18next.t('volui:advanced.archerUnit') }];

// DOĞRU — init sonrası çalışır
function buildDataTable(): HTMLElement {
  const rows = [{ name: i18next.t('volui:advanced.archerUnit') }];
}
```

## Dil değişimi

Uzun ömürlü bir yüzey `languageChanged`e abone olur ve kapanışında aboneliği
BIRAKIR; bırakmayan yüzey eski DOM'a yazmaya devam eder.

```ts
private readonly onLanguageChanged = (): void => {
  this.title.setContent(i18next.t('volhell:menu.title'));
};

create(): void {
  i18next.on('languageChanged', this.onLanguageChanged);
}

onShutdown(): void {
  i18next.off('languageChanged', this.onLanguageChanged);
}
```

Dil değişiminde yüzeyi tümüyle yeniden kuran bir yüzey (`vol-ui` showcase gibi)
ayrıca listener taşımaz.

## Dinamik anahtarlar

Eşleme tablosu geçerlidir ve statik olarak taranabilir:

```ts
const VARIANT_KEYS: Record<BarVariant, string> = {
  health: 'volui:hud.health',
  stamina: 'volui:hud.stamina',
};
```

Şablon değişmezi (`` `volui:touch.dir_${direction}` ``) taranamaz. Bu yüzden
ölü anahtar kapısı (`scripts/quality/deadI18n.mjs`) böyle üretilen anahtarları
TAM AD listesiyle muaf tutar ve muafiyeti üreten kodun hâlâ var olduğunu
doğrular — kod silinirse muafiyet düşer. Yeni bir şablon anahtarı eklemek, o
listeye de eklemeyi gerektirir.
