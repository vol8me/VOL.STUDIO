# Glif varlıkları — kaynak kaydı

Bu dizin, Kenney'nin **Input Prompts 1.5** paketinden seçilmiş bir alt
kümedir. Tamamı CC0 1.0 Universal lisansı altındadır (bkz.
`LICENSE.txt`).

| Alan         | Değer                                                         |
| ------------ | ------------------------------------------------------------- |
| Kaynak       | https://kenney.nl/assets/input-prompts                        |
| Sürüm        | Input Prompts 1.5 (2026-01 güncellemesi)                      |
| Lisans       | CC0 1.0 Universal — atıf gerekmez, her türlü kullanım serbest |
| Alınan biçim | SVG vektörleri (`*/Vector/`)                                  |
| Tarih        | 2026-09-28                                                    |

Aile dizinleri mantıksal slot eşlemesiyle `core/src/ui/glyphs/` tarafından
kullanılır:

- `valve/` — `Steam Deck/Vector` (steamdeck\_\* dosyaları)
- `xbox/` — `Xbox Series/Vector`
- `playstation/` — `PlayStation Series/Vector`
- `nintendo/` — `Nintendo Switch/Vector`
- `keyboard/` — `Keyboard & Mouse/Vector` (klavye + fare aynı ailede)

Dosya adları kaynak paketteki hâlleriyle korunur; yalnız eşleme tablosunda
listelenen slotlar alındı (paket ~4700 dosya, burada 139).
