# i18n

`I18n` i18next tabanlı paylaşılan metin kaynağıdır. CORE metinleri core ad
alanındadır; tüketici kendi ad alanı ve tr/en JSON dosyalarını taşır.
Dokümanın Türkçe olması ürünün iki dilli metin sözleşmesini değiştirmez.

## Başlatma

```ts
import { i18n } from '@volstudio/core';
import tr from '@/i18n/tr.json';
import en from '@/i18n/en.json';

i18n.addResources('tr', 'game', tr);
i18n.addResources('en', 'game', en);
await i18n.init({ saveManager, saveKey: 'device.locale' });
```

Init öncesi resources kuyruğa alınır. Kayıtlı tercih tespitten önce gelir;
tespit navigator.languages, navigator.language ve fallbackLocale sırasındadır.
Varsayılan fallback Türkçe'dir. Dil tercihi cihaz kapsamındaki depolamadadır.

## Görünen metin

Kullanıcı metni anahtardan gelir; modül yüklenirken t çağrılmaz. Yüzey kurulup
kaynak hazırken metin çözülür. tr.json ve en.json aynı anahtar kümesine
sahiptir; paket keyParity testi bunu sınar. Ölü anahtar kapısı tüketilmeyen
metni reddeder.

Dil değişimine abone yüzey kapanışta unsubscribe yapar. Kendini dil değişiminde
yeniden kuran yüzey eski aboneliği tutmaz. Programatik test reset'i ürünün dil
yaşam döngüsü değildir; `i18n.reset` yalnız testte kullanılır.

## Tip ve dinamik anahtar

CORE anahtarları i18next augmentation ile tip denetimine girer. Runtime'da
yüklenen tüketici ad alanları keyParity ve ölü anahtar kapısıyla korunur.
Dinamik seçimde statik eşleme tablosu tercih edilir. Template anahtar
statik taranamıyorsa tam anahtar listesi ölü anahtar kapısında gerekçeli
kayıttır; üreten kod silinince kayıt da silinir.

Yeni dil CORE ve tüketici resources'larına, preloadLocales listesine,
tip augmentation ve dil seçimine birlikte eklenir. Eksik anahtar sessiz
ürün varsayılanına bırakılmaz.
