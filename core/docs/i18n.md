# Core i18n Sistemi

## Mimarı

`I18n` sınıfı (`core/src/systems/I18n.ts`) `i18next` üzerine inşa edilmiş bir lifecycle yöneticisidir. Tek bir `i18n` singleton'ı tüm paketler tarafından paylaşılır.

```
core/src/systems/I18n.ts        — I18n sınıfı + i18n singleton
core/src/i18n/tr.json           — Türkçe çeviriler (core namespace)
core/src/i18n/en.json           — İngilizce çeviriler (core namespace)
core/src/@types/i18next.d.ts    — Compile-time type augmentation
```

## Namespace

Core UI çevirileri `core:` namespace'i altındadır. Çeviri dosyaları `core/src/i18n/{tr,en}.json`'da bulunur.

```typescript
import { i18next } from '@volstudio/core';
const label = i18next.t('core:carousel.prev');
```

## Başlatma

`i18n.init()` çağrılmadan önce hiçbir `i18next.t()` çağrısı çalışmamalıdır. Init sırası:

1. `i18n.addResources('tr', 'volhell', volhellTr)` — oyun çevirileri init öncesi yüklenebilir
2. `await i18n.init({ saveManager })` — i18next başlatılır, pending resource'lar uygulanır
3. Artık `i18next.t()` güvenle çağrılabilir

`addResources()` init öncesi çağrılırsa, resource'lar `pendingResources` kuyruğuna alınır ve init sonrası uygulanır. Init sonrası çağrılırsa anında uygulanır.

## Type Augmentation

`core/src/@types/i18next.d.ts` core namespace key'lerini compile-time doğrular:

```typescript
declare module 'i18next' {
  interface CustomTypeOptions {
    defaultNS: 'core';
    resources: { core: typeof coreTr };
  }
}
```

Bu sayede `i18next.t('core:olmayan.key')` TypeScript hatası verir. Oyun namespace'leri (`volhell:`, `volui:`) runtime'da `addResources()` ile yüklendiği için type augmentation'a dahil değildir — bu key'lerin varlığı manuel doğrulanmalıdır.

## Dil Değişimi

```typescript
await i18n.changeLanguage('en');
```

`languageChanged` olayı yayılır. DOM UI component'leri bu olaya abone olarak içeriklerini canlı günceller. Abonelik örneği:

```typescript
private readonly onLanguageChanged = (): void => {
  this.titleText.setContent(i18next.t('core:carousel.prev'));
};

create(): void {
  i18next.on('languageChanged', this.onLanguageChanged);
}

onShutdown(): void {
  i18next.off('languageChanged', this.onLanguageChanged);
}
```

**Önemli**: `languageChanged` listener'ları `SHUTDOWN`'da mutlaka kaldırılmalıdır. Kaldırılmazsa sahne yeniden başlatıldığında çift abonelik oluşur.

## Dil Tespiti

`detectLocale()` sırasıyla kontrol eder:
1. `navigator.languages[]` — tarayıcının dil listesi
2. `navigator.language` — tarayıcının ana dili
3. `fallbackLocale` (varsayılan: `'tr'`)

`SaveManager` verilirse, kayıtlı dil tercihi tespit edilen dilden öncelikli olur.

## Kurallar

- **Module-level `i18next.t()` yasaktır.** Import sırasında çağrılırsa boş string döner.
- **tr.json ve en.json key parity zorunludur.** Bir dile key eklersen diğerine de ekle.
- **Hardcoded UI string yasaktır.** Tüm kullanıcı görür metinler `i18next.t()` ile çağrılmalı.
- **`i18n.reset()` sadece test amaçlıdır.** Production'da kullanma.
- Yeni core component'i eklenince çeviri key'leri `core/src/i18n/{tr,en}.json`'a eklenmeli ve type augmentation otomatik devreye girecek.

## Yeni Dil Ekleme

1. `core/src/i18n/{dil}.json` oluştur (örn. `de.json`)
2. `init({ preloadLocales: ['tr', 'en', 'de'] })` veya `addResources('de', 'core', deCore)` ile yükle
3. `core/src/@types/i18next.d.ts`'e `de: typeof deCore` ekle (compile-time doğrulama için)
4. Ayarlar ekranında dil seçeneğini ekle
