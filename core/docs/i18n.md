# i18n

`I18n` (`core/src/i18n/I18n.ts`) `i18next` üzerine kurulu, bütün paketlerin
paylaştığı tek örnektir (`i18n`). CORE'un metinleri `core:` ad alanındadır
(`core/src/i18n/{tr,en}.json`); her tüketici yüzey kendi ad alanını ve
`src/i18n/{tr,en}.json` dosyalarını taşır.

## Başlatma

```ts
import { i18n } from '@volstudio/core';
import tr from '@/i18n/tr.json';
import en from '@/i18n/en.json';

i18n.addResources('tr', 'game', tr);
i18n.addResources('en', 'game', en);
await i18n.init({ saveManager, saveKey: 'device.locale' });
```

`addResources()` init'ten önce çağrılırsa kaynak kuyruğa alınır ve init
sonrası uygulanır. Kayıtlı dil tercihi tespit edilen dilden önceliklidir;
tespit sırası `navigator.languages` → `navigator.language` → `fallbackLocale`
(`'tr'`).

## Kurallar

- **Metin sabit yazılmaz.** Kullanıcıya görünen her dize bir anahtardan gelir.
  Sayılar, CSS sınıfları ve font adları metin değildir.
- **`tr.json` ile `en.json` aynı anahtarları taşır.** Her paketin `keyParity`
  testi bunu doğrular.
- **Modül düzeyinde `i18next.t()` çağrılmaz.** Import anında init bitmemiştir
  ve çağrı boş dize döner; çağrı yüzeyi kuran fonksiyonun içinde olur.
- **Dil değişimine abone olan yüzey kapanışta aboneliği bırakır**, yoksa
  sahne yeniden başlayınca çift abonelik oluşur. Dil değişiminde kendini
  baştan kuran yüzey dinleyici taşımaz.
- `i18n.reset()` yalnız testler içindir.

```ts
private readonly onLanguageChanged = (): void => {
  this.title.setContent(i18next.t('game:menu.title'));
};
create(): void {
  i18next.on('languageChanged', this.onLanguageChanged);
}
onShutdown(): void {
  i18next.off('languageChanged', this.onLanguageChanged);
}
```

## Tip denetimi

`core/src/i18n/i18next-augment.ts` `core:` anahtarlarını derleme anında
doğrular; `i18next.t('core:olmayan.anahtar')` tip hatasıdır. Tüketici ad
alanları çalışma anında yüklendiği için bu denetime girmez; onları `keyParity`
testi ve ölü anahtar kapısı korur.

## Dinamik anahtarlar

Eşleme tablosu statik olarak taranır ve tercih edilir:

```ts
const VARIANT_KEYS: Record<BarVariant, string> = {
  health: 'volui:hud.health',
  stamina: 'volui:hud.stamina',
};
```

Şablon değişmeziyle üretilen anahtar (`` `volui:touch.dir_${direction}` ``)
taranamaz. Ölü anahtar kapısı (`scripts/quality/deadI18n.mjs`) böyle
anahtarları tam ad listesiyle muaf tutar ve üreten kod silinince muafiyeti
düşürür; yeni bir şablon anahtarı o listeye de yazılır.

## Yeni dil

1. `core/src/i18n/<dil>.json` ve tüketicilerin `<dil>.json` dosyaları eklenir.
2. `init({ preloadLocales: ['tr', 'en', '<dil>'] })`.
3. `i18next-augment.ts` yeni dili tanır.
4. Ayar ekranına dil seçeneği eklenir.
